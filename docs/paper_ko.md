# Spatial-Multimodal-2Mo: KITTI 장면 그래프 기반 Ego 안전 판정 파이프라인 — 논문 요약 (국문)

## 초록
본 연구는 KITTI 다중모달(ego 영상·라이다·텍스트) 장면에서 장면 그래프 지식을 추출하여
자율주행 ego 차량의 안전 판정(CANNOT/SAFE)을 내리는 파이프라인을 제시한다.
60장면 검증 벤치마크에서 현재 정합률 18.9%로 85% 게이트에 미달한다. 원인은 CANNOT
판정 분기: 취약 개체·횡단보도·중차량 전방 차단 관계가 최종 판정으로 일관 전파되지
않기 때문이다.

## 1. 서론
자율주행은 해석 가능한 그래프 기반 추론을 요구한다. 파이프라인은 장면 설명을 입력받아
장면 그래프(개체+공간 관계)를 구축하고, 취약 도로 사용자·전방 차단 트리플을 추론하여
CANNOT 또는 SAFE를 출력한다.

## 2. 방법
1) 캡션 생성 2) 개체/관계 추출 → 장면 그래프 3) 전방 위험 분석(취약 개체·중차량·횡단보도/무단횡단)
4) 판정: 전방 위험이 있으면 CANNOT, 없으면 SAFE.

## 3. 벤치마크
- 60 KITTI 검증 장면(gold= CANNOT/SAFE).
- bench_v49: Cloudflare 터널 경유 demo 엔드포인트 호출; gold는 staged reasoning 최종단계/answer
  힌트에서, 판정은 서버 응답 토큰에서 추출.
- 게이트: 정합률 ≥85%.

## 4. 결과
- 총 53장면(7장면 gold NONE 제외), 정합 10, 불일치 43, 정합률 18.9% → 게이트 FAIL.
- 불일치: CANNOT gold 장면 다수가 SAFE로 판정되며 일부는 HTTP 500.

## 5. 원인 분석
취약 개체 전방 판정이 특정 트리플 형태(`is_ahead_of` to ego, 또는 취약 클래스의
`near_crosswalk`)에만 반응한다. 무단횡단·횡단보도 점유·정지선 위반·Tram/Truck/Van 전방
차단 장면이 CANNOT으로 매핑되지 않음 = 판정 분기 버그.

## 6. 결론
게이트 미달. 판정 분기 패치(횡단 점유·정지선 위반·중차량 차단 → CANNOT) 후 서버 재시작과
재벤치가 선행되어야 게이트를 통과할 수 있다.
