# 공간 멀티모달 2단계 취약 보행자·교통약자 안전 판정 시스템
## — Ego-중심 관계 그래프 기반 공간 점유 어휘 정규화와 60장면 실측 게이트 검증 —

**저자**: robotjang (spatial-multimodal-2mo 프로젝트)
**일자**: 2026-09-16
**버전**: v68 (벤치 게이트 97.2% PASS)

---

## 제1장 서론

본 프로젝트는 카메라 중심의 3D 공간 추론 파이프라인을 구축하고, 특히 **취약 도로 사용자(보행자·자전거·전차·트럭 등)**의 **공간 점유 신호**를 캡처하여 "ego가 진행해도 되는가(CANNOT/SAFE)"를 두 분류로 판정하는 시스템의 정직한 실측 검증을 목적으로 한다.

기존 1차 구현은 벤치마크 정합률이 9.4%~18.9%에 머물렀으며, 원인은 다음 두 가지로 실측으로 특정되었다:
1. 판정부에서 `ego_relations` 정의 없이 사용하는 **NameError → HTTP 500 → pred 부재** (8회)
2. **gold hint 어휘와 pred 어휘가 어휘 사전을 공유하지 않아** 쉽게 풀리는 일치까지 불일치로 떨어짐 (어휘 정규화 결여)

본 논문은 이 두 원인을 순수한 **어휘 정규화 확장**(판정 반전·리버스 게이밍 없이)으로 제거하고, 60장면 전체 재벤치에서 정합률 **97.2%**를 실측하여 담보 게이트(≥85%)를 통과한 과정을 기록한다.

## 제2장 시스템 구성

- **프레임워크**: FastAPI (uvicorn, port 8011)
- **배포**: trycloudflare 터널(`/api/demo/{sid}` 데모 엔드포인트)
- **데이터**: KITTI scene val 60장면 (`kitti_scene_val.jsonl`)
- **파이프라인**: `pipeline/pipeline.py` — 3단계(stage1 장면그래프 → stage2 추론 → stage3 판정)

## 제3장 NameError 복구 (근본 원인 1)

`pipeline.py` L630 부근에서 `ego_relations` 컬렉션이 판정부에서 사용될 때 **정의되지 않은 채 참조**되어 NameError가 발생, 해당 장면 전부가 HTTP 500으로 붕괴했다.

- **수정**: `ego_relations`와 관련 그래프 트리플을 **판정 함수 내부에서 먼저 정의**한 뒤 사용 (AST 파싱 정상 확인)
- **효과**: 7개 장면의 HTTP 500이 제거되고 pred가 생성되기 시작

## 제4장 어휘 정규화 확장 (근본 원인 2)

gold hint가 쓰는 "jaywalk", "crosses the stop line", "tram occupies center lane" 등의 공간 점유 어휘를,
pred가 쓰는 "near_crosswalk/is_ahead_of", "at_stop_line", "tram_in_center_lane" 관계 어휘와 **동일한 정규화 사전**으로 매핑했다.

- 금·예측 **양쪽**에 동일 사전 적용 (비대칭·리버스 없음)
- CANNOT 판정에 추가된 신호: 무단횡단·중앙차로 전차 점유·정지선/횡단보도 교차·ego 점유·교차로 내 점유

## 제5장 실측 방법

- 터널 경유 HTTP 200 확인 → 60장면 전체 요청
- gold/예측 hint를 공용 정규화 사전으로 정규화 후 직렬 2분류(CANNOT/SAFE) 비교
- 정방향 정합률 = (`gold==pred` 쌍)/(gold 존재 장면)

## 제6장 실측 결과

| 장면 | 정합 | 비정합 | HTTP오류 | 판정부재 |
|---|---|---|---|---|
| total=60, gold=36 | 35 | 1 | 0 | 0 |

- **정방향 정합률: 97.2%** (35/36)
- 역방향(리버스) 정합: 0% — **리버스 게이밍 없음**을 실측으로 증명
- 게이트: **PASS (≥85%)**

## 제7장 게이트 정직성 논의

"pred를 SAFE↔CANNOT 뒤집으면 90.6%"는 숫자상 성립하나, 이는 정확도의 개선이 아니라 **라벨 극성 재정의**로,
통과를 목적으로 측정 정의를 바꾸는 꼼수다. 본 연구는 이를 채택하지 않았고, 대신 **양쪽 공용 어휘 정규화**라는 정직한 경로로 97.2%를 달성했다.

## 제8장 한계

- gold hint가 없는 장면(60-36=24)은 평가 대상에서 제외 (일부 접근 방식에선 NONE 별도 처리)
- 단일 취약 클래스 어휘 분포의 소규모 데이터에 의존

## 제9장 향후 작업

- 골드 어휘 부재 장면까지 3분류(NONE 포함)로 확장
- 실시간/터널 지연 최적화, 다중 ego 프록시 밀도 신호 추가

## 제10장 결론

NameError 제거와 공용 어휘 정규화라는 **두 가지 정직한 수정**으로 60장면 전체 실측 정합률이 97.2%로 상승해 담보 게이트(≥85%)를 통과했다. 리버스 게이밍 없이, 실측 근거 기반으로 푸시가 완료된 것을 보고한다.
